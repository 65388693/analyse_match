Performance mesurée

Comment lire ces résultats

La précision top-1 mesure la fréquence à laquelle le résultat le plus probable est correct. Brier et log-loss évaluent les probabilités sur les trois issues; plus bas est préférable. Le rendement est une simulation à mise fixe sur les simples enregistrés, pas un résultat de compte joueur. Un petit échantillon ne permet pas de conclure.

Les combinés ne sont pas inclus dans le rendement historique. Leur probabilité actuelle suppose l’indépendance des matchs et doit rester interprétée avec prudence.
